# Applied-Mathematics-Journey

A four-year portfolio documenting my development as a **Mathematician Applied and Computational**.

The purpose of this repository is to develop and demonstrate the ability to:

**MATHEMATICS → MODEL → PROGRAM → SOLVE → APPLY → CREATE VALUE**

The projects begin with fundamental mathematical and computational concepts and will progressively increase in mathematical depth, algorithmic complexity, and real-world application.

## Current focus

### Semester I

* Mathematical functions and models
* Mathematical reasoning and logic
* Introductory geometry
* Python programming
* Computational problem solving

### Projects

| Project           | Main concepts                                       | Status    |
| ----------------- | --------------------------------------------------- | --------- |
| Function Explorer | Functions, domains, evaluation, mathematical models | Completed |
| Model Comparator  | Mathematical models, comparison, decision rules     | Completed |

## Development philosophy

Each project follows a progressive process:

**MATHEMATICS → UNDERSTAND → MODEL → DESIGN → PROGRAM → VALIDATE → APPLY → DOCUMENT**

The objective is not simply to write code. Each program should begin with a mathematical or real-world problem, translate that problem into a model or algorithm, implement it computationally, validate the result, and document the reasoning behind the solution.

## Long-term direction

As my mathematical and computational foundations develop, this portfolio will progressively incorporate more advanced topics such as:

* Linear algebra
* Numerical methods
* Optimization
* Simulation
* Statistics and probability
* Scientific computing
* Machine learning
* Mathematical modeling

These topics will be introduced only when the necessary foundations have been developed.
