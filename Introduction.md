# Introduction

## About this journey

**Applied-Mathematics-Journey** is a four-year portfolio documenting my development in **Applied and Computational Mathematics**.

This repository is a record of how I learn to transform mathematical ideas into computational solutions.

> **MATHEMATICS → MODEL → PROGRAM → SOLVE → APPLY**

The goal is not simply to learn mathematics or programming independently, but to develop the ability to connect both disciplines to understand, model, and solve problems.

## What I am building

Throughout my degree, I intend to progressively develop skills in:

* Mathematical reasoning
* Mathematical modeling
* Programming and algorithms
* Computational thinking
* Data analysis
* Numerical and scientific computing
* Problem solving
* Technical communication

The projects will increase in mathematical depth and computational complexity as my knowledge develops.

## How I work

My projects follow a cycle:

**UNDERSTAND → MODEL → DESIGN → PROGRAM → VALIDATE → APPLY → DOCUMENT**

Each project begins with a mathematical concept or a problem. I first try to understand the underlying mathematics, formulate a model or algorithm, design a computational solution, implement it, validate the result, and document what I learned.

The objective is to build **understanding and problem-solving ability**, not simply to produce code.

## Starting point

This journey begins with fundamental mathematics and programming.

My first projects focus on:

* Functions and mathematical models
* Logic and sets
* Elementary geometry
* Python programming
* Basic algorithms
* Translating mathematical reasoning into computational procedures

These projects are intentionally simple. Their purpose is to establish the foundations on which more sophisticated mathematical and computational work can later be built.

## Long-term vision

As the mathematical foundation becomes stronger, this portfolio will progressively explore more advanced areas such as:

* Linear algebra
* Numerical methods
* Optimization
* Simulation
* Statistics and probability
* Scientific computing
* Machine learning
* Mathematical modeling

The direction will evolve according to what I learn, what problems I encounter, and where mathematics can create useful computational solutions.

---

**This is not a collection of finished work. It is a record of becoming capable of using mathematics to solve problems computationally.**
